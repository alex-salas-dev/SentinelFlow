# SentinelFlow

SentinelFlow es una plataforma de monitorización y observabilidad orientada a la recepción, almacenamiento, análisis y visualización de eventos técnicos.

## Stack principal

- Backend: Spring Boot
- Frontend: React
- Analytics: Python
- Base de datos: PostgreSQL
- Cache / procesamiento rápido: Redis
- Infraestructura local: Docker Compose

## Estado del proyecto

Proyecto actualmente en fase de inicialización.

### Roadmap inicial

- Sprint 0 - Foundation & Architecture
- Sprint 1 - API de recepción de eventos
- Sprint 2+ - Evolución progresiva de observabilidad, análisis y visualización
